# Curated Occupations List (MVP)

**Total:** 70 occupations
**Selection Strategy:** Hybrid (50-60 most popular + 10-20 for RIASEC balance)
**Last Updated:** November 20, 2025

---

## Selection Criteria

### Primary: High-Demand/Popular Careers (50-60)
- High employment size (>10,000 workers nationally)
- Relevant to target audience (knowledge workers, 25-45 age)
- Transferable skills focus
- Growth outlook: Stable or growing

### Secondary: RIASEC Balance (10-20)
- Minimum 5 occupations per RIASEC primary type
- Ensures every user gets relevant matches
- Includes less common but valuable roles

## Usage Instructions

### Phase 0, Week 3: Data Seeding

1. Use this list as input to `seed-occupations.ts` script
2. Fetch each occupation from O*NET API using code
3. Validate RIASEC codes match this list
4. Seed to PostgreSQL `occupations` table

### Future Expansion (Phase 2D)

When migrating to full database:
- Keep these 70 as "core" occupations (always show)
- Add 230-430 more from ETL pipeline
- Ensure no duplicates (check O*NET code)

## Notes

**Salary Data Source:** O*NET 28.0 (2024), national median salaries in USD

**Employment Data:** Based on Bureau of Labor Statistics Occupational Employment Statistics

**RIASEC Codes:** Primary type shown (e.g., "IRC" = Investigative primary, Realistic secondary, Conventional tertiary)

**Selection Bias:** Skewed toward knowledge work (tech, business, healthcare, education). Underrepresented: manual labor, agriculture, military. This matches target user persona (25-45, career-seeking professionals).
